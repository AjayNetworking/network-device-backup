# Network Device Backup Tool

A Python-based network automation project for backing up network device configurations.

## About This Project

This project is designed for network engineers who want to automate network device configuration backups.

## Goals

- Connect to network devices using SSH
- Retrieve running configurations
- Save configuration backups
- Automate repetitive network administration tasks

## Technologies

- Python
- Netmiko
- SSH
- Git
- GitHub
